# Tauri rental App V1

Sistema de escritorio multiplataforma, inteligente y de alta eficiencia para la gestión integral de alquileres y activos físicos, diseñado bajo arquitectura hexagonal. Desarrollado con Tauri & Rust.

---

## 🚀 Características Principales

**### 📈 Motor Analítico Local (Python + Pandas)**
*(Aquí colocas tu imagen_2.png)*
El sistema integra un microservicio local conectado mediante `fetch` que permite a la aplicación de escritorio procesar grandes volúmenes de datos históricos y generar reportes analíticos de rentabilidad, tiempos promedio y tendencias, sin saturar la interfaz de usuario.

**### 🗺️ Mapeo Espacial y Visualización 3D**
*(Aquí colocas tu imagen_3.png)*
Utilizando librerías Open Source, implementamos un visor cartográfico interactivo que permite la ubicación geométrica exacta de los activos físicos. La visualización en 3D facilita la gestión de inventario en almacenes complejos o en campo.

**### ⚙️ Gestión Integral de Inventario**
*(Aquí colocas tu imagen_4.png)*
Administración avanzada del ciclo de vida del alquiler, permitiendo registrar nuevos equipos, controlar fechas límite, estados de devolución y ubicaciones físicas de los activos de forma eficiente.

---
## 🛠️ Tecnologías Utilizadas
- **Frontend / Core Desktop:** Tauri, Rust, React, TypeScript.
- **Análisis de Datos:** Python, Pandas.
- **Visualización:** Mapas 3D Open Source.
